Primeros pasos

Instalación y apertura

La instalación actual está orientada a Linux y requiere una terminal. Una placa gráfica es opcional.

Requisitos de sistema

sudo apt update
sudo apt install -y git python3 python3-venv python3-pip   tesseract-ocr tesseract-ocr-spa ffmpeg

Instalar Archive Workbench

git clone https://github.com/alexdcolman/archive-workbench.git
cd archive-workbench
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e ".[extraction,streamlit,tiff]"

La búsqueda semántica, la incorporación desde plataformas y otros backends se instalan como extensiones opcionales cuando se necesitan.

Extensiones opcionales

pip install -e ".[semantic]"
pip install -e ".[platform]"
./scripts/install_surya_runtime.sh --dry-run
./scripts/install_surya_runtime.sh

Abrir o crear un proyecto

source .venv/bin/activate
archive-workbench review-app

La pantalla inicial permite Abrir un proyecto existente o Crear un proyecto nuevo. También puede abrirse una carpeta conocida directamente:

archive-workbench review-app mi_proyecto

Migraciones: un proyecto existente se migra sólo después de crear y verificar un backup. No se ejecuta db-upgrade por rutina.
