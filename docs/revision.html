Imagen, texto y decisiones

Revisar documentos con el original a la vista

La revisión mantiene el documento y la página como contexto estable mientras se seleccionan bloques, se corrige texto y se registran decisiones.

Corregir texto

La imagen y los bloques de texto permanecen sincronizados. Seleccionar un recuadro cambia el bloque activo; guardar una corrección requiere una acción explícita.

Casilleros y campos

La pestaña organiza detección, alta manual, revisión de casilleros confirmados, grupos e historial como tareas separadas para reducir densidad.

Orden y estructura

Las propuestas de columnas y orden de lectura son revisables. La representación visual permanece principal y el detalle tabular puede abrirse cuando hace falta.

Historial

Las correcciones y operaciones relevantes conservan historial. Deshacer o restaurar no borra el hecho de que existió una decisión anterior.
