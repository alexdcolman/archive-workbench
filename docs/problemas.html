Problemas frecuentes

La aplicación no abre

Comprobá que el entorno virtual esté activo y que la instalación incluya el extra streamlit. Ejecutá archive-workbench review-app desde la carpeta del proyecto de código.

Un proyecto existente pide migración

Consultá primero archive-workbench db-status RUTA_DEL_PROYECTO. Creá y verificá un backup antes de ejecutar una migración. No repitas db-upgrade si el proyecto ya está en la revisión vigente.

El OCR no usa Surya

Surya vive en un entorno separado. Usá el diagnóstico de extracción y comprobá el runtime antes de cambiar perfiles. Si no está disponible, el perfil puede recurrir a Docling/Tesseract.

La GPU sigue ocupada

Consultá archive-workbench surya-server-status y, cuando no haya un trabajo activo que necesite conservar el servidor, usá archive-workbench surya-server-stop.

La búsqueda semántica no devuelve resultados esperados

Comprobá que exista un índice para el perfil actual y recordá que la similitud semántica no constituye una decisión analítica. Compará con búsqueda textual y revisá el alcance del índice.

Un paquete de intercambio no se puede aplicar

Inspeccioná el paquete y ejecutá la simulación. Si existe un conflicto de linaje o estado, utilizá las acciones específicas de resolución; no copies una base SQLite sobre otra.

Diagnósticos y soporte

Cuando informes un error, conservá el mensaje exacto, la sección donde ocurrió, la operación que lo produjo y la versión de Archive Workbench. No incluyas originales restringidos ni datos personales si no son necesarios para reproducirlo.
