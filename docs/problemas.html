Soporte

Problemas frecuentes

Estas rutas de diagnóstico usan los nombres actuales de la interfaz. Cuando un problema puede afectar la integridad del proyecto, conviene comenzar por Administrar y recuperar → Integridad.

La distribución administrada no abre

Comprobá que Docker esté instalado y disponible. En Windows y macOS abrí Docker Desktop antes de volver a ejecutar el lanzador. En Linux comprobá que docker info y docker compose version funcionen. Los lanzadores muestran las últimas líneas del servicio cuando la aplicación no llega a iniciar.

Un proyecto existente pide migración

Consultá primero archive-workbench db-status RUTA_DEL_PROYECTO. Creá y verificá una copia de seguridad antes de ejecutar archive-workbench db-upgrade RUTA_DEL_PROYECTO. No repitas la migración si el proyecto ya está en la revisión vigente.

Un archivo registrado aparece como ausente

Abrí Administrar y recuperar → Integridad y revisá el aviso correspondiente. El catálogo conserva la identidad del objeto digital aunque una copia de archivo no esté disponible en la ruta registrada.

El OCR no usa el motor esperado

En Procesar documentos revisá el perfil seleccionado y los detalles de la corrida. Surya puede ejecutarse como un servicio local separado; otros perfiles pueden utilizar Tesseract o Docling según la instalación y la configuración.

La GPU sigue ocupada después de una tarea

En una instalación técnica desde terminal puede consultarse archive-workbench surya-server-status y detenerse un servidor sin trabajo activo con archive-workbench surya-server-stop. Las tareas normales de interfaz liberan el servidor cuando el perfil no solicita conservarlo.

La búsqueda semántica no devuelve resultados esperados

Comprobá en Búsqueda semántica → Configurar el índice de búsqueda que el índice esté actualizado y que incluya los tipos de bloque y estados de revisión necesarios. La similitud coseno depende del conjunto de textos incluido en el índice, del perfil y del modelo que transforma los textos en representaciones numéricas; compará el resultado con el contexto documental.

Una referencia a entidad quedó desactualizada después de corregir el texto

Abrí Entidades y menciones → Buscar nuevas entidades → Duplicados y cambios de texto → Actualizar referencias después de corregir el texto. La sección muestra las referencias que necesitan volver a ubicarse y conserva el historial de la decisión.

Un paquete de intercambio no puede aplicarse

Abrí Intercambiar cambios → Recibir cambios y revisá el diagnóstico del ZIP. La aplicación compara el paquete antes de escribir. Si las copias no reconocen un punto de partida compatible, utilizá Resolver un problema entre copias; no copies una SQLite sobre otra de manera manual.

Quiero comprobar si una copia de seguridad realmente abre

Usá Administrar y recuperar → Probar recuperación. La prueba se realiza en un entorno temporal y no reemplaza el proyecto activo.

Reporte de errores

Conservá el mensaje exacto, la sección y pestaña donde ocurrió, la operación que lo produjo y la versión de Archive Workbench. Si el problema involucra un archivo del proyecto, evitá compartir originales restringidos o datos personales cuando no sean necesarios para reproducirlo.
