Referencia

Conceptos

Estas definiciones explican los objetos que aparecen en la interfaz y en la referencia técnica. Los términos describen capas distintas del proyecto y conviene no tratarlos como sinónimos.

Proyecto
Carpeta de trabajo que reúne configuración, una base de datos local SQLite, archivos incorporados o vinculados, resultados derivados, exportaciones y copias de seguridad.
Unidad del catálogo
Registro descriptivo de una parte del archivo o del contexto de custodia, por ejemplo un fondo, una sección, una serie o una unidad documental, según los niveles definidos para el proyecto.
Archivo digital
Objeto identificado por su contenido digital. Puede tener una o más copias de archivo registradas en ubicaciones concretas.
Archivo original
Archivo incorporado como fuente. Su contenido no se sobrescribe durante el reconocimiento óptico de caracteres (OCR), la revisión o el análisis.
Derivado
Archivo o representación producido a partir de una fuente, por ejemplo una imagen preparada para OCR. Conserva la referencia al archivo del que proviene.
Corrida
Ejecución concreta de un proceso, como OCR o transcripción, con motor de procesamiento, versión, modelo, opciones y fecha identificables.
Extracción de texto
Resultado de una corrida de reconocimiento sobre un documento o página. Puede haber varias extracciones disponibles para comparar.
Texto elegido para revisión
Extracción completa que una persona seleccionó como punto de partida para una página en Revisar documentos.
Capa editable
Texto y estructura que se corrigen en Revisar documentos. Las modificaciones generan revisiones nuevas y no reescriben el archivo original.
Bloque de texto
Parte delimitada de una página, como un párrafo, título o encabezado, que puede editarse y revisarse de manera independiente.
Revisión
Versión registrada después de una modificación explícita. Las revisiones permiten reconstruir el historial de un bloque, una unidad, una entidad u otros objetos versionados.
Entidad
Referente reutilizable del corpus, por ejemplo una persona, organización, lugar, acontecimiento u obra.
Mención
Aparición concreta de una entidad o posible entidad en un texto. La mención conserva el fragmento y su ubicación documental.
Relación
Vínculo registrado entre dos elementos. Puede expresar estructura archivística, producción o gestión, una mención documental o una relación analítica.
Evidencia
Información que sustenta una relación, decisión o descripción, por ejemplo un pasaje documental o una referencia bibliográfica.
Procedencia
Registro del origen de un dato o resultado: archivo, página, corrida, persona, operación o fuente externa que permite reconstruir cómo llegó al estado actual.
Índice textual
Estructura reconstruible utilizada para buscar coincidencias de palabras o frases dentro de los textos del proyecto.
Índice semántico
Estructura reconstruible que representa fragmentos mediante vectores numéricos para compararlos por similitud de significado.
Paquete incremental
ZIP con cambios realizados en una copia después de un punto compartido. Se inspecciona y simula antes de aplicarse en otra copia compatible.
Copia completa para trabajar en equipo
ZIP que transporta la base y configuración del proyecto y, según el perfil elegido, archivos originales, derivados, transcripciones u otros materiales. Sirve para iniciar una nueva copia local del mismo proyecto.
Copia de seguridad
Estado verificable del proyecto preparado para recuperación. Puede probarse en un entorno temporal antes de una restauración real.
