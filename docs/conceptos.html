Decisiones metodológicas

Conceptos para interpretar el proyecto

Archive Workbench separa deliberadamente datos canónicos, candidatos automáticos, decisiones explícitas y resultados reconstruibles.

ConceptoQué significa
OriginalArchivo incorporado cuya identidad se conserva; no se modifica durante OCR o revisión.
DerivadoRepresentación preparada a partir del original, con procedencia y parámetros.
CorridaEjecución identificable de un procesamiento o análisis con configuración registrada.
CandidataSalida automática disponible para revisión; todavía no es una decisión explícita.
Selección canónicaElección explícita de la extracción que alimenta la revisión de una página.
Capa editableTexto versionado que conserva correcciones, historial y vínculos analíticos.
AutoridadRegistro canónico de una entidad; se distingue de las menciones concretas.
ÍndiceEstructura reconstruible para búsqueda; no sustituye la fuente de verdad SQLite.

Confianza y automatización

Una puntuación de similitud, un OCR o una propuesta de entidad no constituyen una verdad documental. La interfaz conserva la procedencia de esas salidas para que puedan revisarse y compararse.
